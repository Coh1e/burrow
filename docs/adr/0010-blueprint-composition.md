# 由用户组合蓝图表达使用场景

Burrow 的核心是 Digby 和可组合的蓝图。用户通过组合表达项目环境、工作站配置等用途。其他工具的设计可供借鉴，读取 `pixi.toml` 或 `mise.toml` 不属于蓝图的兼容契约。

第一阶段的验收目标是同一份蓝图可在 Windows、Linux 和 macOS 上解释。作者可以声明步骤适用的平台，预览须说明跳过原因。当前平台缺少某个必需步骤所需的能力时，Digby 须在首次写入前报告缺项。验收时在三个平台分别运行同一份含平台专属步骤的蓝图。

首版按作者声明的顺序组合和执行步骤，预览采用相同顺序。每个步骤仍可解析内部依赖，例如先安装依赖包再安装请求的包。这样，即使后续动作通过外部命令使用前一步准备的工具，作者也能确定两者的执行顺序。

蓝图可以同时包含目标状态和显式动作。预览对已经满足的目标状态显示“已满足”，对选中的显式动作显示“将执行”。例如，再次应用同一份蓝图时，已有的 PATH 条目会保留，项目测试会重新运行。

同一份子蓝图在多个位置被引用时，每处引用都按所在位置执行。到达该位置时，Digby 重新检查目标状态并执行选中的显式动作。若引用形成循环，Digby 在规划时报告完整引用链，并在首次写入前停止。

步骤失败时，Digby 保留已完成步骤的结果，报告失败步骤，并停止后续步骤。外部命令已启动后失败，报告须说明它可能已产生副作用。用户重新应用蓝图时，Digby 从头按序检查目标状态，并重新执行选中的显式动作。

如果前序动作可能改变后续步骤要检查的状态，预览保留步骤顺序，列出外部命令及参数，将受影响的目标状态标为“执行时检查”并说明原因。实际执行到该步骤时，Digby 读取当时的状态，决定跳过或修改。

预览和执行报告通过同一条引用路径定位步骤。路径从根蓝图开始，逐层标明引用在所属蓝图中的位置，最后标明步骤在所属蓝图中的位置。这样即使同一父蓝图两次引用同一个测试蓝图，也能辨认哪一次通过、哪一次失败，以及哪些后续步骤尚未执行。

子蓝图声明输入，父蓝图在每处引用时显式传参。各处引用的参数独立。若缺少必填输入，Digby 在首次写入前报告引用位置和参数名。

外部命令默认由程序名和参数列表组成，Digby 直接启动程序并保留每个参数的边界。需要管道、重定向或 shell 变量展开时，作者显式指定解释器，由该解释器处理脚本语法。

子蓝图声明具名输出。父蓝图从指定的那次引用取值，交给后续步骤使用。对于执行时才能确定的值，预览标明来源步骤和输出名称，执行到相应位置时再取值。

蓝图中声明的相对文件引用，以声明该引用的蓝图文件所在目录为基准。调用方可显式传入项目目录作为外部命令的工作目录。例如，共享蓝图从自身目录定位构建脚本，并在调用方指定的源码目录运行它。

若当前平台选中的步骤需要某项输出，而提供该输出的调用因平台条件被跳过，Digby 在首次写入前报错，指出两处位置和输出名称。若调用实际运行后缺少必需输出，Digby 将该次调用记为失败，停止后续步骤。

作者可以选择锁定某项软件。锁定记录按平台保存解析出的版本、来源和产物摘要。普通应用沿用锁定结果，作者显式更新时才重新选择版本。

要求锁定的软件在当前平台缺少记录，或记录中的版本与蓝图要求不符时，Digby 在首次写入前停止，报告软件、目标平台和具体原因。用户显式生成或更新记录后再应用蓝图。

锁定范围包含 Digby 为该软件解析出的全部直接和间接软件依赖。只有能确认本机已有依赖与对应锁定记录匹配时，才可复用。操作系统版本、驱动等宿主条件单独检查。

同一软件的多个版本可并存。蓝图可为一个动作选定锁定版本；改变用户默认命令入口须由作者另行声明为目标状态，并在预览中列出受影响的入口。

宿主条件只声明要求时，Digby 检查条件，在不满足时报告检测值与要求值，停止依赖该条件的操作。作者可在蓝图中显式安排修复步骤；预览列出该步骤，执行后重新检查条件，通过后才执行依赖它的操作。

首版允许作者用外部程序的只读检查和变更动作组合出可复用的目标状态。预览可运行只读检查；若前序动作可能改变结果，仍标为“执行时检查”。应用时，检查结果为已满足则跳过，为未满足则执行变更并复查。检查出错或复查未能确认目标已满足时，报告失败并停止。插件接口留待具体扩展需求出现时再决定。

每条外部检查命令可声明退出码映射。默认以 0 表示目标已满足，作者显式列出表示未满足的退出码。其余退出码及进程启动失败均为检查错误，Digby 报告错误并停止。若工具通过标准输出返回目标状态，作者可以用脚本将查询结果转换为约定的退出码。

首版以一份可运行的蓝图作为验收入口。同一份蓝图在三个平台分别构建 Debug 和 Release，只测试 Release 调用的输出。另行注入锁定记录缺失、外部检查报错和第二次构建失败，核对预览、执行位置及最终状态。参见[首版验收清单](../blueprint-acceptance.md)。
